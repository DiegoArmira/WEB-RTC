## Regla de documentación vigente

Antes de implementar, Codex debe consultar CAP-02 para APIs y dependencias de las **versiones realmente instaladas**. Si Context7 no está configurado o no puede resolver la biblioteca, debe usar la documentación oficial equivalente y registrar el origen en la bitácora del spec; no debe depender solo del conocimiento interno del modelo.

## Límite de autorización

Este documento decide el paquete que Bootstrap deberá materializar. No autoriza instalar dependencias, configurar Context7, descargar navegadores, crear subagentes, ni ejecutar Codex.
